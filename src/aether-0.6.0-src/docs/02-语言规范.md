# Aether 语言规范（v0.1）

## 1. 词法
- 注释：`// ...`
- 标识符：字母/下划线/**中文**开头（`view 首页 {}` 合法）
- 字面量：`42` `3.14` `"文本 {表达式插值}"` `true` `false` `nil`；`\{` 转义花括号
- 换行不敏感（但调用 `f(x)` 与索引 `a[i]` 要求 `(`/`[` 与前一记号在同一行）

## 2. 声明
```aether
module 名称
import "other.ae"                      // 引入另一文件的声明

entity Todo {                          // 数据实体 → 存储表 + REST API + 表单
  title: Text
  done: Bool = false                   // 默认值
}

type Shape = Circle(r: Float) | Rect(w: Float, h: Float) | Dot   // 代数数据类型

fn area(s: Shape) -> Float ! pure { ... }     // 函数：参数类型、返回类型、效果
fn id<T>(x: T) -> T { x }                     // 泛型

action toggle(t: Todo) { t.done = not t.done } // 服务端动作：实体参数按 id 自动加载并保存

view 首页 {                            // 视图 → 自动渲染的页面
  title "我的待办"
  text "说明文字"
  stat "完成数" count(Todo)            // 服务端求值的统计
  form Todo                            // 根据字段类型自动生成表单
  list Todo title                      // 列表（可指定标题字段），自动附带行级 action 按钮
  table Todo
  chart Post likes                     // 数值字段条形图
  button "清空" -> clear_done          // 触发无参 action
}

flow 发布 { step "审核" { ... } step "上线" { ... } }   // 流程（MVP 仅解析与检查）
```

## 3. 语句与表达式
| 能力 | 语法 |
|---|---|
| 绑定 | `let x = 1`（不可变）、`var n = 0`（可变）、`let x: Int = 1` |
| 赋值 | `n = 2` `n += 1` `rec.field = v` `xs[0] = v` |
| 条件（表达式） | `if c { a } else if d { b } else { c }` |
| 循环 | `while c { }`、`for x in xs { }` |
| 模式匹配 | `match v { 0 => "零", x if x < 0 => "负", Circle(r) => r, [a, b] => a, _ => "其他" }` |
| 函数值 / 闭包 | `fn(x) => x + 1`、`fn(x) { ... }` |
| 管道 | `xs |> filter(fn(x) => x > 0) |> map(f) |> sum` （`a |> f(b)` 即 `f(a, b)`） |
| 方法糖 | `xs.len()` 即 `len(xs)` |
| 记录 / 列表 | `{name: "Ada", age: 36}`、`[1, 2, 3]`、`p.name`、`xs[0]` |
| 异常 | `throw v`、`try { } catch e { }` |
| 并发 | `let f = spawn work(x)`；`await f`；`await [spawn a(), spawn b()]` |
| 块值 | 块的最后一个表达式即其值；`return` 可提前返回 |

## 4. 类型系统（MVP）
- 内置类型：`Int Float Text Bool List<T> Map Record Any Nil Fn Future Date`，`T?` 可空，实体名与 `type` 声明均为类型。
- 检查器做：类型名存在性、字面量/简单表达式的类型推断、`let` 标注与返回类型一致性、`Int → Float` 隐式提升、函数与构造器参数个数、模式中构造器存在性、非穷尽 match 警告。
- 运行时为动态强类型（错误类型的运算报 `R008`）。完整的 Hindley-Milner 推断见路线图。

## 5. 效果系统
每个内置函数带效果标签：`print→io`、`all/insert/...→db`、`now/sleep→time`、`http_get→net`、`random→random`、`spawn/await→async`。
函数用 `! io, db` 声明效果。检查器会**传递地**计算函数实际效果，未声明时给出 `W300` 警告和修复提示（智能体可一键修复）。`action` 和顶层代码默认允许所有效果。

## 6. 统一应用模型的编译语义
| 源 | 存储 | API | 界面 |
|---|---|---|---|
| `entity E {f: T}` | SQLite 表 `E`，列按类型映射；新字段**自动迁移**（ALTER TABLE） | `GET/POST /api/E`，`GET/PUT/DELETE /api/E/{id}` | 表单、列表、表格 |
| `action a(x: E)` | 事务内加载、执行、回写 | `POST /api/action/a {"x": id}` | 列表每行自动出现按钮 |
| `action a()` | — | `POST /api/action/a` | `button "…" -> a` |
| `view V {…}` | — | `GET /api/_meta`（UI 规格 JSON） | 顶部导航中的一个页面 |
| 全体 | — | `GET /api/_openapi` | — |

## 8. 诊断码
`E0xx` 词法，`E1xx` 语法，`E2xx` 名称/类型/视图（E200 未定义名、E201 未知类型、E220/221 类型不符、E222 运算符、E23x 视图引用、E240 参数个数、E250 构造器），`W300` 效果，`W310` 穷尽性，`R0xx` 运行时，`A0xx` 智能体操作。

## 9. v0.2 新增：契约、内嵌测试、权限、流程
```aether
entity Account {
  owner: Text
  balance: Int = 0
  invariant balance >= 0            // 每次写入前检查（R040）
}

fn fee(x: Int) -> Int
  requires x >= 0                   // 前置条件（R041）
  ensures result <= x               // 后置条件，result = 返回值（R042）
{ x }

action reset() allow admin, auditor { ... }   // 角色权限；HTTP 头 X-Aether-Role，不符返回 403

example fee(10) == 10               // 示例即测试
test "不能透支" { assert(...) }       // aether test 运行

flow 月结 {                          // 可执行流程：顺序执行，ctx 共享状态，失败即停
  step "计息" { ... }
  step "报告" { "总额 {ctx.total}" }
}
```
新增诊断：W320（example 应为布尔表达式）、R040/R041/R042（契约违反）、R050（流程不存在）、H001/H002（无可撤销/重做）。
新增 CLI：`aether test | explain | flow | history | undo | redo | hash`。
