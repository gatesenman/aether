# 路线图

| 阶段 | 内容 |
|---|---|
| **0.1（当前 MVP）** | 解释器、基础类型检查、效果警告、统一应用模型（entity/view/action）、SQLite、REST、自动 UI、Studio、结构化补丁协议、mock/LLM 智能体、安装包 |
| **0.2（当前）** | 范式原则（docs/paradigm.md）、契约 requires/ensures/invariant、内嵌 example/test、内容寻址历史与出处、撤销/重做、自然语言解释投影、角色权限、可执行 flow |
| 0.3 | 完整类型推断（HM + 行多态记录）、泛型约束、Result/Option 与 `?` 运算符、模块命名空间与包管理 |
| 0.4 | 持久化工作流（重试、定时、人工审批）、权限与身份（`policy`）、实时订阅（视图自动 WebSocket 同步）|
| 0.4 | 字节码 VM / 编译到 WASM 与 JS，前端可离线运行；LSP 服务器（VS Code 等编辑器）|
| 0.5 | 多渲染器（移动端、桌面、语音）、可插拔存储（Postgres、KV、CRDT 本地优先同步）|
| 1.0 | 形式化语义、效果与权限的可验证补丁（每个智能体修改附带检查证明）、多智能体协作协议 |

## 当前已知限制（诚实说明）
- 解释执行，性能约为 CPython 的 1/50 量级，适合原型与中小应用，不适合高负载生产。
- 类型检查是"尽力而为"的局部推断，不保证类型安全；运行时动态检查兜底。
- 没有身份认证/权限，API 默认只监听 127.0.0.1。
- `flow` 在内存中同步执行，不持久化、不可恢复；`import` 只做文件级合并，无命名空间。
- UI 渲染器提供固定组件集（title/text/stat/form/list/table/chart/button），不支持自定义布局与样式。
- 格式化器只规范缩进与空行，不做完整重排。
- mock 智能体是规则匹配，只理解少数句式；真实智能能力需配置 `AETHER_LLM_API_KEY`（OpenAI 兼容接口）。
- 契约只在运行时检查，没有静态证明；不变式只能引用本实体的字段。
- 角色来自请求头，没有身份认证，任何客户端都能自称 admin，仅供演示。
- 历史的"可逆"靠保存每个版本的快照；内容寻址只做到整个程序级别，不到函数级别。
- 解释投影基于规则模板，复杂表达式以「…」省略。
- `aether test` 的测试共用一个内存数据库，测试之间可能互相影响。
