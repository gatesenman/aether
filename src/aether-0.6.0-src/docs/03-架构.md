# 架构

```
           ┌──────────── Aether Studio (Web IDE, aether/ide.py) ─────────────┐
 人 ──编辑──▶ 编辑器 │ 诊断 │ AST/IR │ 输出 │ 实时预览 iframe │ 智能体面板 ◀── LLM / mock
           └──────┬───────────────────────────────┬──────────────────┬─────┘
                  ▼                               ▼                  ▼
 .ae 源码 ─▶ lexer.py ─▶ parser.py ─▶ JSON AST(IR) ─▶ checker.py ─▶ 结构化诊断
                                         │                 ▲
                                         │          agent.py（结构化操作 → 补丁 → 复检 → diff）
                                         ▼
                                   interp.py（解释器：闭包/ADT/匹配/异常/线程池并发）
                                         │  stdlib.py（带效果标签）
                                         ▼
                                   app.py（统一应用编译器）
                                   ├─ storage.py：entity → SQLite 表 + 自动迁移
                                   ├─ REST/JSON API + OpenAPI
                                   └─ UI 规格(JSON) + 通用渲染器(浏览器端 JS)
```

- **零依赖**：仅用 Python 3.9+ 标准库（http.server、sqlite3、concurrent.futures）。
- **IR 优先**：AST 节点是纯 JSON 字典，每个顶层声明带源码 span，智能体的结构化操作据此精确拼接源码，保留人类的格式与注释。
- **UI 不是代码生成，而是"规格 + 渲染器"**：服务端把 view 编译成 UI 规格 JSON，浏览器端一个通用渲染器负责展示。未来可替换为原生/移动/语音渲染器而不改源程序。
- **Studio 预览**：每次通过检查即重建内存应用，并把旧数据迁移到新 schema，实现"改字段即见效"。
- **CLI**（aether/cli.py）：`run check serve studio fmt ast ops propose new version`。
