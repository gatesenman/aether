# 智能体协议（Agent Protocol）

智能体不直接改文本，而是提交**结构化操作**；系统应用后自动复检并返回 diff，由人决定是否接受。

## 操作集
```json
{"op":"add_decl","code":"entity Note { title: Text }"}
{"op":"replace_decl","name":"toggle","code":"action toggle(t: Todo) { ... }"}
{"op":"remove_decl","name":"表格"}
{"op":"add_field","entity":"Todo","field":"due","type":"Text","default":"\"\""}
{"op":"remove_field","entity":"Todo","field":"priority"}
{"op":"rename","old":"Todo","new":"Task"}          // 基于词法，不会误改字符串内容（插值中的标识符会同步）
{"op":"add_view_item","view":"首页","item":"stat \"总数\" count(Todo)"}
{"op":"set_effects","fn":"progress","effects":["db"]}
```

## HTTP 端点（Studio 内）
| 端点 | 说明 |
|---|---|
| `GET /agent/schema` | 操作集 schema + 语言简介（可直接放入 LLM 系统提示） |
| `POST /agent/propose {source, prompt}` | 智能体给出 `{mode, summary, ops, source, diff, diagnostics, ok}` |
| `POST /agent/apply {source, ops}` | 确定性地应用操作并复检 |
| `POST /ide/check {source}` | `{diagnostics, ast}` |
| `POST /ide/run` / `/ide/fmt` / `/ide/preview` / `/ide/save` | 运行 / 格式化 / 热更新预览 / 保存 |

## CLI
```bash
aether ast app.ae                    # JSON IR
aether check app.ae --json           # 结构化诊断
aether ops app.ae '[{"op":"add_field","entity":"Todo","field":"due","type":"Text"}]' -w
aether propose app.ae "给 Todo 添加字段 due: Text"
```

## 接入真实大模型
```bash
export AETHER_LLM_API_KEY=sk-...
export AETHER_LLM_BASE_URL=https://api.openai.com/v1   # 任何 OpenAI 兼容服务
export AETHER_LLM_MODEL=gpt-4o-mini
```
不设置时自动使用 mock 模式；LLM 调用失败会自动回退到 mock 并在摘要中注明。
